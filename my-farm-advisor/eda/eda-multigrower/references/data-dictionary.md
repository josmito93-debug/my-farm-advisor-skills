# Derived EDA data dictionary

Columns in the committed tables under
[`../examples/output/`](../examples/output/). All tables are generated by
`generate_eda_multigrower.py`; raw inputs stay in the runtime.

## `dataset_field_summary.csv`

One row per field (30 rows). Boundary geometry is projected to EPSG:5070
(equal-area, metres) before measurement.

| Column | Unit | Meaning |
| --- | --- | --- |
| `grower` | — | State code used in labels: `IL`, `IA`, `NE` |
| `state` | — | Full state name |
| `grower_slug` | — | Runtime grower folder, e.g. `il-grower` |
| `farm` | — | Runtime farm slug, e.g. `il-grower-illinois` |
| `county` | — | Farm home county |
| `field_id` | — | OSM/Overpass polygon identifier |
| `area_acres` | acres | Polygon area, EPSG:5070 area / 4,046.8564224 |
| `perimeter_km` | km | Polygon boundary length / 1,000 |
| `polsby_popper` | 0–1 | `4*pi*area / perimeter^2`; 1.0 is a perfect circle |
| `shape_index` | ≥1 | `perimeter / (2*sqrt(pi*area))`; 1.0 circle, 1.13 square |

`polsby_popper` and `shape_index` are reciprocal descriptions of the same
geometry; the report uses each where it reads more naturally.

## `analysis01_boundary_comparison.csv`

Statistical tests on field area and compactness across growers.

| Column | Meaning |
| --- | --- |
| `test` | `kruskal_wallis` (all growers) or `mann_whitney_u` (pairwise) |
| `metric` | `area_acres` or `polsby_popper` |
| `group_a`, `group_b` | Compared groups; `group_b` is blank for the omnibus test |
| `n_a`, `n_b` | Sample sizes; `n_b` is 0 for the omnibus test |
| `statistic` | H statistic (Kruskal-Wallis) or U statistic (Mann-Whitney) |
| `p_value` | Raw p-value |
| `p_adjusted` | Holm-adjusted p-value within each metric's pairwise family |
| `effect_size` | Rank-biserial correlation for Mann-Whitney; blank for omnibus |
| `interpretation` | Plain-language reading of the result |

## `analysis01_boundary_summary.csv`

One row per grower (`grower` index). Columns are `<metric>_<statistic>`, e.g.
`area_acres_median`, `area_acres_mean`, `area_acres_std`, `area_acres_min`,
`area_acres_max`, for `area_acres`, `perimeter_km`, `polsby_popper`, and
`shape_index`.

## `analysis02_weather_comparison.csv`

Seasonal weather summaries and tests. The season is April 1 – September 30
(DOY 91–273).

| Column | Meaning |
| --- | --- |
| `test` | `spearman_correlation`, `kruskal_wallis`, or `yearly_mean` |
| `comparison` | Grower code, `all growers`, or `<grower> <year>` |
| `metric` | `seasonal_gdd_vs_precip`, `seasonal_gdd`, `seasonal_precip`, or `seasonal_gdd` for yearly means |
| `statistic` | Spearman rho, Kruskal-Wallis H, or the yearly mean value |
| `p_value` | p-value for tests; blank on `yearly_mean` rows |
| `effect_size` | Spearman rho for correlations; blank otherwise |
| `n` | Field-year pairs contributing to the row |
| `detail` | Scope note; yearly rows also carry that year's seasonal precipitation in mm |

GDD is computed per day as `max((min(T2M_MAX, 30) + max(T2M_MIN, 10)) / 2 - 10, 0)`
and summed over the season.

## `analysis03_cdl_comparison.csv`

Crop-mix comparisons between CDL and weather.

| Column | Meaning |
| --- | --- |
| `test` | `chi_square`, `spearman_correlation`, or `yearly_mean` |
| `comparison` | `crop mix across growers`, `all growers`, a grower code, or a grower name for mean rows |
| `metric` | `dominant_crop`, `corn_share_vs_gdd`, or `corn_share` |
| `statistic` | Chi-square statistic, Spearman rho, or mean corn share in percent |
| `p_value` | p-value for tests; blank on `yearly_mean` rows |
| `effect_size` | Cramér's V for chi-square, rho for correlations; blank otherwise |
| `n` | Field-years contributing to the row |
| `detail` | Degrees of freedom, overlap window, or scope note |

Crop classes are collapsed to `Corn`, `Soybeans`, and `Other` from the CDL
crop names; shares are normalised to 100% of classified field area per
field-year. Corn-share correlations use the 2021–2023 overlap between CDL
(2019–2023) and weather (2021–2025).

## Figure inputs

The figures are drawn from the same derived frames, not from these CSVs:
`fig01`/`fig02` from per-field geometry, `fig03`/`fig04` from field-year
seasonal weather, `fig05`/`fig06` from field-year CDL composition, and
`map01` from boundary polygons plus geoadmin state/county layers.
